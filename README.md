# QEdu
Edupage 2.0 web application school platform for online learning
License:Apache 2.0

Frameworks
Frontend: Next.js + React,
Frontend runtime: Node.js,
Backend: Java Spring Boot,
API: REST,
Database: PostgreSQL,
Database host: Neon or AWS,

Timetable, 
Statistics,
Database,
Login,
Session handling,
Roles,
School events,
Frontend,
UI,
Tests,
Projects,
Study materials, 
Meal plan,
Data input,
Student evaluation, 
Messages.
